# Image Rules

## Main Cover

The main cover must be generated directly as a finished cover.

Do:

- include the exact short Chinese title in the prompt
- include the industry visual elements from the profile
- use safe margins
- request vertical 3:4
- make each cover visually different
- inspect final preview when possible

Do not:

- generate a background and overlay title afterward
- use blurred side borders or blurred padding
- use phone UI screenshots as the cover frame
- reuse the same layout for every hotspot
- crop title text at the edges

## Support Cards

Support cards can be rendered with scripts for text accuracy.

Card 2 usually explains the hotspot/problem.
Card 3 usually connects the industry workflow/solution.

Use:

- large Chinese text
- 3 to 5 bullets
- clear hierarchy
- simple palette variation

## Visual Differentiation

Same hotspot with multiple posts must still vary:

- scene: lab, desk, field, shop, factory, classroom, dashboard, etc.
- palette
- object focus
- text title
- metaphor
- character placement

## Size

Default final size: `1080x1440`.

If the generator returns a slightly different 3:4 size, resize/crop carefully to `1080x1440`. Avoid resizing a wrong ratio if it would crop important title text; regenerate instead.
